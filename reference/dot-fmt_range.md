# Format a numeric vector as a bracketed min-to-max range string

Format a numeric vector as a bracketed min-to-max range string

## Usage

``` r
.fmt_range(x, digits = 3L)
```

## Arguments

- x:

  `numeric`.

- digits:

  `integer`. Significant digits. Default `3`.

## Value

A `character` scalar giving the min and max, or `"NA"`.
